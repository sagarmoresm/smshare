COMMON QUESTIONS

Frequently asked questions

How long does my content stay live?
By default, 30 minutes. Before sending you can choose 30 minutes, 2 hours, 12 hours, or 24 hours. When the time is up, the content and its code are hard-deleted — there is no way to recover them.
Is SMSHARE really anonymous?
Yes. There is no account, no email, no phone number, and no sign-up of any kind. We do not log IP addresses and we do not use cross-site tracking cookies to identify you.
What is the file size limit?
Each file can be up to 500 MB, and you can attach up to 10 files at once — images, PDFs, ZIPs, videos, audio, and documents.
What happens when a code expires?
The code stops working permanently. Entering an expired code returns nothing, and the database record along with any stored files are immediately purged from disk.
Is my data encrypted?
All traffic is transmitted over HTTPS (TLS). Files are saved with randomized internal IDs in temporary self-purging storage partitions.
Can I download multiple files at once?
Yes! If a sender uploads multiple files, you can preview and download them individually or click the "Download All as ZIP" button to get everything bundled in one archive.
